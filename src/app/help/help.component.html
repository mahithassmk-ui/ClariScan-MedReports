Help & Workflow

Everything you need to use the report simplifier quickly and safely.

01

Open Home

Go to the Home page to start a new report simplification.

02

Upload File

Select one report file in PDF or image format.

03

Generate Report

Click Generate Simplified Report and wait for processing.

04

Review Output

Read the simplified summary and risk color indicators.

05

Download PDF

Use Download Current View as PDF to save a copy.

Accepted Formats

  • PDF (`.pdf`)
  • Image (`.jpg`, `.jpeg`, `.png`)

Best Upload Quality

  • Use original digital PDF when possible.
  • If image, keep it high-resolution and well-lit.
  • Avoid blurry or cropped text.

Safety Note

This tool provides educational simplification only and does not replace doctor consultation.
